# Roomies — User Stories

## Roles

1. **Visitor** — not signed in.
2. **Member** — acts as **Host** on the properties/listings they own, and as **Seeker** on everyone else's. Host and Seeker are not separate accounts or roles; they are the same Member role seen from two different relationships to a listing — ownership is what determines the permission, not the label.
3. **Moderator** — everything a Member can do, plus platform-wide moderation powers.

## User Stories

### Publishing a property and the listings inside it

1. As a Member (Host), I want to register my property with its address, neighborhood, property type, number of bedrooms and bathrooms, shared spaces, and amenities, so that I can publish rooms inside it.
2. As a Member (Host), I want to publish a listing for an available room, with its rent, deposit, availability date, minimum stay, furnishing, private bathroom, description, house rules, and photos, so that seekers can find it and decide whether to apply.

### Searching and browsing listings as a visitor who is not signed in

3. As a Visitor, I want to search listings by neighborhood, maximum rent, availability date, and amenities, so that I can find rooms that match what I'm looking for.
4. As a Visitor, I want to view a listing's full details such as photos, description, rent, property amenities, and reviews, so that I can decide whether to apply once I create an account.

### Applying to a listing, and withdrawing an application

5. As a Member (Seeker), I want to apply to a listing with a short introduction, my desired move-in date, and how long I intend to stay, so that I can be considered for the room.
6. As a Member (Seeker), I want to withdraw an application I sent, so that I'm no longer considered for that room.

### Shortlisting applications, arranging a visit, and accepting one applicant

7. As a Member (Host), I want to shortlist a promising application, so that I can arrange a visit before deciding.
8. As a Member (Host), I want to propose a visit date and time to a shortlisted applicant, so that we can see the room together.
9. As a Member (Seeker), I want to confirm a proposed visit, or wait for a new date if the host cancels it, so that I know when to show up.
10. As a Member (Host), I want to mark a visit as completed, so that the seeker can review the property afterward.
11. As a Member (Host), I want to accept one applicant for my listing, so that the room is filled, every other application on it is automatically rejected, and the listing becomes reserved.

### Reviewing a property after visiting it

12. As a Member (Seeker), I want to leave a rating and comment on a property after a completed visit, so that other people looking for a room know what to expect.

### Saving listings and reporting a listing

13. As a Member (Seeker), I want to save a listing, so that I can find it again later.
14. As a Member, I want to report a listing that looks fraudulent, misleading, or offensive, so that a moderator can review it and take it down if needed.

### Moderation of reported listings and management of the neighborhood and amenity catalogs

15. As a Moderator, I want to review reported listings and take down those that are fraudulent, misleading, or offensive, so that the platform stays trustworthy.
16. As a Moderator, I want to remove a review that is abusive or inappropriate, so that the content on the platform stays appropriate.
17. As a Moderator, I want to add, edit, or remove entries in the neighborhood and amenity catalogs, so that hosts have accurate and consistent options when publishing listings.
